API (Upload) Keys

API keys authenticate uploads to this server's API (/api/v1): SwarmDialer benchmark and hardware reports, and hardware reports from the hardware collection script. An API key can only upload reports: it can't read, list or delete them, and it can't log in to this interface. Create one API key per site or network, so it can be revoked on its own.
